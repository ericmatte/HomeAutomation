# Escape Room v2 — univers narratifs alternatifs (non retenus)

Pour la v2, l'univers **Enquête / meurtre mystère** a été retenu. Les trois
autres pistes explorées sont conservées ici pour de futures itérations (v3+).

## 1. L'IA de la maison devient consciente

La maison elle-même (via Home Assistant) prend vie : elle parle par tous les
haut-parleurs, joue avec les lumières / volets / robot aspirateur, et lance un
défi aux invités.

- **Angle méta** : chaque entité devient un « organe » du personnage — parfait
  showcase domotique.
- **Ton** : ludique ou légèrement menaçant (HAL 9000 mais fun).
- **Mécanique possible** : reprendre le contrôle pièce par pièce ; l'IA
  « teste » les invités avant de leur rendre la maison.

## 2. Compte à rebours / désamorçage

Urgence scénarisée : « système en surchauffe / intrusion / fuite » à stopper
avant la fin d'un timer.

- **Ton** : tension, adrénaline.
- **Ambiance** : sons d'alarme, lumières rouges pulsées, étapes contre la
  montre.
- **Mécanique possible** : plusieurs stations à désarmer dans un ordre précis,
  minuteur global visible/annoncé.

## 3. Paranormal / esprit dans la maison

Un esprit « habite » la domotique et communique.

- **Ton** : mystère / frisson.
- **Ambiance** : clignotements = oui/non, volets qui bougent seuls,
  chuchotements localisés dans une seule pièce, objets qui réagissent.
- **Mécanique possible** : séance interactive, poser des questions à l'esprit
  qui répond via les lumières et les capteurs.
